Solution

Only four bytes are initially copied into an RWX mapping, but the function pointer is invoked with stdin, the mapping address, and 0x1000 already in rdi, rsi, and rdx. Use the four-byte stager xor eax,eax; syscall to perform read(0, upload, 0x1000).

The second read overwrites the mapping. Put four disposable bytes first so execution resumes at offset four, followed there by normal execve shellcode that reads the flag.
