Challenge package

Players receive chall.js and the remote endpoint. The service accepts one short expression, checks the raw text with an extremely confident filter, and then gives the same text to JavaScript's considerably less impressed parser.

The public description and service banner are intentionally sarcastic:

Parser vs filter.

>

We taught a regex to understand JavaScript. The language specification can retire now.

The challenge starts at 200 points and has a minimum value of 100.
