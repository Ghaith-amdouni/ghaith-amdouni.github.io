Solution

The program discloses the address of stdout, which gives the libc base by subtracting the bundled libc's _IO_2_1_stdout_ offset. The 72-byte read into a 32-byte stack buffer also reaches the saved return address at offset 40.

Build a libc ROP chain with an alignment ret, pop rdi; ret, the address of /bin/sh, and system. After the function returns into the chain, send cat flag.txt through the resulting shell.
