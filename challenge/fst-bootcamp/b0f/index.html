Vulnerability

int check = 0xdeadbeef;
char buffer[64];
gets(buffer);  // UNLIMITED input!
if (check == 0xcafebabe) {
    system("cat flag.txt");
}

Classic gets() overflow. The check variable sits directly above buffer on the stack. We overflow 64 bytes of buffer + overwrite check with 0xcafebabe.
