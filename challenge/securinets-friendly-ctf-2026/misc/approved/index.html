Challenge

The player receives only the extensionless file final. It is a valid TeX DVI document composed entirely of rules, so it requires no external fonts.

Mechanism

DVI is a small page-description virtual machine. Its horizontal w and x register instructions both store a signed distance and move the cursor by that distance. Because this document never reuses either register with w0 or x0, the following instruction families render identically:

The operand width is independently varied between three and four bytes. NOPs, ordinary right/down movements, stack operations, and random y/z vertical choices provide unrelated bytecode noise.

The four physical pages are deliberately stored out of order. The first of the ten counters in each bop instruction gives its logical page number.

Solution

  1. Run file final to identify TeX DVI version 2.
  2. Parse the preamble and each bop/eop page body.
  3. Record 0 for explicit w1..w4 instructions and 1 for x1..x4.
  4. Sort the bit arrays by each page's first bop counter.
  5. Concatenate them and pack bits most-significant-bit first.
