Challenge package

Players receive only chall.py and the remote endpoint. The public description and every message printed by the service are intentionally sarcastic and reveal nothing about the underlying construction.

The flag is 98 characters long, exactly twice the 49-character flag used by the inspiration challenge. The challenge begins at 999 points.

Intended solution

The source builds a deterministic Huffman tree for the flag and returns the encoded bit string without the tree. Its second action repeatedly chooses a uniformly random flag position and returns

where P is a degree-five polynomial with six unknown positive integer coefficients.

  1. Request the second action many times. The relative occurrence count of each returned integer reveals the corresponding character frequency. Fit positive integer frequencies whose sum is the known flag length, 98.
  2. All polynomial coefficients are positive. On positive inputs, P is strictly increasing, so sorting its outputs gives the same ordering as sorting the original characters.
  3. Assign an ordered proxy alphabet to the sorted outputs. Combine the recovered frequencies with the source's frequency-and-symbol tie break to rebuild the exact Huffman tree, then decode the bit string into proxy characters.
  4. The first six flag characters are the distinct, known characters Securi. Their proxy characters identify six polynomial outputs. Solve the resulting six-by-six Vandermonde system to recover all six coefficients of P.
  5. Evaluate P over printable ASCII, map each output back to its proxy symbol, and substitute through the decoded proxy text.

The supplied solver uses a constrained maximum-likelihood fit for the integer frequencies, exact rational Gaussian elimination for the polynomial, and checks that the recovered flag reproduces the original bit string.
