Chop's Last Fetch

CyberLeek entrusted the final piece of the GTA VI build to the only courier in Los Santos who could never be bribed, traced, or questioned. Chop still has the drop, but he only listens to handlers who can follow every command without falling behind. Keep up, and he may return with more than a stick.

Solution

This is a timed parser challenge. For each of 45 rounds, read the exact package length and apply every command from left to right. FETCH leaves the bytes alone; the remaining operations reverse, change case, repeat, rotate left, slice with an exclusive end, sort, XOR into lowercase hexadecimal, or return the byte count.

Using the advertised package length avoids delimiter mistakes. Send the transformed bytes before the two-second alarm on every round to receive the flag.
